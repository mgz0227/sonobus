# DemoGain_ParamValueInfo

Demonstrates implementation of `GetParameterValueInfo()` to provide EQ band type, in-circuit polarity, and alternate control information for proper display on attached control surfaces. This example shows how to map internal parameter values to AAX page table selectors including `AAX_ePageTable_EQ_Band_Type`, `AAX_ePageTable_EQ_InCircuitPolarity`, and `AAX_ePageTable_UseAlternateControl`.
