\doxysubsection{Description}
Interface to information about the host\textquotesingle{}s transport state. 

\begin{DoxyRefDesc}{\+:\+Implemented by the AAX Host}
\item[\mbox{\hyperlink{a00884__aax_host_implementation000013}{\+:\+Implemented by the AAX Host}}]\end{DoxyRefDesc}


Plug-\/ins that use this interface should describe \mbox{\hyperlink{a00737_a13e384f22825afd3db6d68395b79ce0daf3e1162c5f517595589d513d48158dbd}{AAX\+\_\+e\+Property\+\_\+\+Uses\+Transport}} as 1

Classes that inherit from \mbox{\hyperlink{a01852}{AAX\+\_\+\+CEffect\+Parameters}} or \mbox{\hyperlink{a01848}{AAX\+\_\+\+CEffect\+GUI}} can use \mbox{\hyperlink{a01852_af003e341f47eb1f170529db63066eca3}{AAX\+\_\+\+CEffect\+Parameters\+::\+Transport()}} / \mbox{\hyperlink{a01848_a5a034e713b03fb4591e45c2e7167189d}{AAX\+\_\+\+CEffect\+GUI\+::\+Transport()}} to access this interface. This interface is used as a local interface to the \mbox{\hyperlink{a02436}{AAX\+\_\+\+VTransport}} versioned implemenation, which dispatches calls to the appropriate host-\/supplied versioned transport interface depending on which features are supported by the host. See \mbox{\hyperlink{a01852_a245f235300b04f1c8b4c83831d296e22}{AAX\+\_\+\+CEffect\+Parameters\+::\+Initialize()}} for an example.

A copy of this interface may also be obtained directly from the host using \mbox{\hyperlink{a02292_a57bd132ee74047e25298b157c0bff2f9}{AAX\+\_\+\+IMIDINode\+::\+Get\+Transport()}}. However, in this case the interface is not versioned, so the host and the plugin may not agree on the interface. This can lead to undefined behavior. See the documentation at \mbox{\hyperlink{a02292_a57bd132ee74047e25298b157c0bff2f9}{AAX\+\_\+\+IMIDINode\+::\+Get\+Transport()}} for more information. \doxysubsection*{Public Member Functions}

{\footnotesize\ttfamily virtual \mbox{\hyperlink{a00410_a4d8f69a697df7f70c3a8e9b8ee130d2f}{AAX\+\_\+\+Result}} AAX\+\_\+\+ITransport\+::\+Get\+Current\+Native\+Sample\+Location (\begin{DoxyParamCaption}\item[{int64\+\_\+t $\ast$}]{Sample\+Location }\end{DoxyParamCaption}) const\hspace{0.3cm}{\ttfamily [pure virtual]}}



CALL\+: Gets the current playback location of the native audio engine. 

When called from a Process\+Proc render callback, this method will provide the absolute sample location at the beginning of the callback\textquotesingle{}s audio buffers.

When called from \mbox{\hyperlink{a00902_gae6139041de22f51f3146d26a01c54c1b}{AAX\+\_\+\+IEffect\+Parameters\+::\+Render\+Audio\+\_\+\+Hybrid()}}, this method will provide the absolute sample location for the samples in the method\textquotesingle{}s {\bfseries{output}} audio buffers. To calculate the absolute sample location for the sampels in the method\textquotesingle{}s input buffers (i.\+e. the timelin location where the samples originated) subtract the value provided by \mbox{\hyperlink{a00902_ga47b471c438fcad0798964b860d74609e}{AAX\+\_\+\+IController\+::\+Get\+Hybrid\+Signal\+Latency()}} from this value.

When called from a non-\/real-\/time thread, this method will provide the current location of the samples being processed by the plug-\/in\textquotesingle{}s Process\+Proc on its real-\/time processing thread.

\begin{DoxyNote}{Note}
This method only returns a value during playback. It cannot be used to determine, e.\+g., the location of the timeline selector while the host is not in playback.
\end{DoxyNote}
