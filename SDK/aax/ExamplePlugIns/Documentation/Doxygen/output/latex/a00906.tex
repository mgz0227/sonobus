\hypertarget{a00906}{}\doxysection{Properties File}
\label{a00906}\index{Properties File@{Properties File}}
Properties for an AAX plugin bundle. 

\doxyparagraph*{About}



An XML properties file can optionally be used in an AAX plugin bundle to provide information to the host prior to loading the plugin binary.

The file should be named AAXProperties.\+xml and should be placed in the bundle\textquotesingle{}s Resources folder.



\doxyparagraph*{Collection Properties}



{\ttfamily Auth\+Dialog} (Optional) 
\begin{DoxyItemize}
\item Required attribute\+: {\ttfamily type\+\_\+=\char`\"{}bool\char`\"{}}  
\item Value {\ttfamily true}\+: Declares that the plugin may show an authorization dialog when loaded.  
\item Value {\ttfamily false}\+: Declares that the plugin will never show an authorization dialog when loaded.  
\end{DoxyItemize}
