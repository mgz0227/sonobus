\hypertarget{a00908}{}\doxysection{Task agent interface}
\label{a00908}\index{Task agent interface@{Task agent interface}}


\doxysubsection{ }
A mechanism for hosts to request that plug-\/ins perform tasks. 

{\itshape This interface represents an optional component that you can add to your plug-\/in in order to support extended features of the AAX SDK.}

\begin{DoxyRefDesc}{Host Compatibility Notes}
\item[\mbox{\hyperlink{a00879__compatibility_notes000002}{Host Compatibility Notes}}]This interface is not yet used in any AAX hosts\end{DoxyRefDesc}


The plug-\/in implements an \mbox{\hyperlink{a02348}{AAX\+\_\+\+ITask\+Agent}}, which is used by the host to add or cancel tasks.

The host implements \mbox{\hyperlink{a02164}{AAX\+\_\+\+IACFTask}} for task objects representing each task that it wants the plug-\/in to perform.

To request a task, the host adds a task object to the plug-\/in\textquotesingle{}s task agent interface.

The type of each task is identified with a four-\/char ID. If additional arbitrary data is necessary to describe the task it is provided via \mbox{\hyperlink{a02228}{data buffers}}.

The plug-\/in checks this data to understand what work needs to be done, then performs the task. The task may be, and usually is, executed asynchronously. The plug-\/in optionally updates the task progress as it proceedds, then calls \mbox{\hyperlink{a02344_a5fcd36f2deeba6c0841a3ae742cf3eae}{AAX\+\_\+\+ITask\+::\+Set\+Done()}} when the work is completed. If the task involves returning data back to the host, the plug-\/in first calls \mbox{\hyperlink{a02344_aa8d9d069296346d40bc105a9a01fb0c1}{AAX\+\_\+\+ITask\+::\+Add\+Result()}} one or more times to provide the data via data buffers.

To be available as a task agent, the plug-\/in\textquotesingle{}s task agent implementation must be registered with the host in the plug-\/in\textquotesingle{}s Description callback like other process pointers. To add this interface to your plug-\/in at describe time, call \mbox{\hyperlink{a02256_ad1a286ef7cb869e6f79423dd774ec976}{AAX\+\_\+\+IEffect\+Descriptor\+::\+Add\+Proc\+Ptr()}} using the \mbox{\hyperlink{a00419_af0682195d377392ad356fd2b00c36892aeba711809f385408668d73d0f20d59eb}{k\+AAX\+\_\+\+Proc\+Ptr\+ID\+\_\+\+Create\+\_\+\+Task\+Agent}} selector.\hypertarget{a00908_auxinterface_task_modulecommunication}{}\doxysubsection{Communicating with other modules}\label{a00908_auxinterface_task_modulecommunication}
Like other modules, the task agent interface is provided with a reference to the plug-\/in\textquotesingle{}s \mbox{\hyperlink{a02260}{AAX\+\_\+\+IEffect\+Direct\+Data}} object at initialization. In order to transfer data between a plug-\/in\textquotesingle{}s \mbox{\hyperlink{a02260}{AAX\+\_\+\+IEffect\+Direct\+Data}} object and its other objects, dedicated custom data methods in those objects\textquotesingle{} interfaces should be used. For example, to communicate with the plug-\/in\textquotesingle{}s data model, use \mbox{\hyperlink{a02068_a4728fcad006d921a07489144360f447e}{AAX\+\_\+\+IEffect\+Parameters\+::\+Get\+Custom\+Data()}} and \mbox{\hyperlink{a02068_aa838cad04781853ef2e0b9df22a05170}{AAX\+\_\+\+IEffect\+Parameters\+::\+Set\+Custom\+Data()}} . \doxysubsection*{Classes}
