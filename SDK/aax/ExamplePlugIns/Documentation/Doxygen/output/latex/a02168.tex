\doxysubsection{Description}
Versioned interface for a component that accepts task requests. 

\begin{DoxyRefDesc}{\+:\+Implemented by the Plug-\/\+In}
\item[\mbox{\hyperlink{a00883__aax_plugin_implementation000001}{\+:\+Implemented by the Plug-\/\+In}}]\end{DoxyRefDesc}


The task agent is expected to complete the requested tasks asynchronously and to provide progress and completion details via calls on the \mbox{\hyperlink{a02164}{AAX\+\_\+\+IACFTask}} interface as the tasks proceed.
