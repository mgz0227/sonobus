\doxysubsection{Description}
Interface representing a request to perform a task. 

\begin{DoxyRefDesc}{\+:\+Implemented by the AAX Host}
\item[\mbox{\hyperlink{a00884__aax_host_implementation000012}{\+:\+Implemented by the AAX Host}}]\end{DoxyRefDesc}


Used by the \mbox{\hyperlink{a02348}{task agent}}.

This interface describes a task request and provides a way for the agent to express one or more results of the task as well as the progress of the task.

This interface is open-\/ended for both inputs and outputs. The host and agent must use common definitions for specific task types, their possible arguments, and the expected results. \doxysubsection*{Public Member Functions}

Attach result data to this task. 

This can be called multiple times to add multiple types of results to a single task.

The host may process the result data immediately or may wait for the task to complete.

The plug-\/in is expected to release the data buffer upon making this call. At a minimum, the data buffer must not be changed after this call is made. See {\ttfamily ACFPtr\+::in\+Arg()}
