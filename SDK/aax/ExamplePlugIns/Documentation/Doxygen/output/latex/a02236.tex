\doxysubsection{Description}
Interface to host services provided during plug-\/in description

\begin{DoxyWarning}{Warning}
AAX plugin description details are cached and might not be re-\/scanned even if attributes of the host description change. Be careful to avoid changing any cacheable information based on this data. See \mbox{\hyperlink{a00889_describe_host_feature_checks}{Host feature and environment checks}} for more information. 
\end{DoxyWarning}

Get the client\textquotesingle{}s feature object for a given feature ID

Similar to {\ttfamily Query\+Interface()} but uses a feature identifier rather than a true IID

Ownership of the returned object is passed to the caller; the caller is responsible for destroying the object, e.\+g. by capturing the returned object in a smart pointer.

If no \mbox{\hyperlink{a02272}{AAX\+\_\+\+IFeature\+Info}} is provided then that may mean that the host is unaware of the feature, or it may mean that the host is aware of the feature but has not implemented the AAX feature support interface for this feature yet.
