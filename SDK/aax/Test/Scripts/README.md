# AAX SDK Unit Test Infrastructure

This directory contains a Python script to build and run the AAX SDK tests in a self-contained environment.

## Usage

### Basic Usage
```bash
# Build and run all available unit tests
python3 build_unit_tests.py

# Clean build artifacts
python3 build_unit_tests.py --clean

# Show help and available options
python3 build_unit_tests.py --help
```

See the `build_unit_tests.py --help` text for more advanced options.

### Build artifacts
All build artifacts and other side effects generated by the build script are contained in the following directories:
- `Test/.venv`
- `Test/.build`
- `Test/Scripts/__pycache__`

### Excluding Tests
Edit `excluded_tests.json` to add or remove tests from the exclusion list. The format for each item in this dictionary is: _target name_: _reason for exclusion_

## Architecture

### Directory Structure
```
Test/
├── Scripts/                    # Testing infrastructure
│   ├── build_unit_tests.py     # Main script
│   ├── excluded_tests.json     # Test exclusion configuration
│   ├── requirements.txt        # Python dependencies
│   ├── conanfile.py            # Conan configuration
│   └── *.py                    # Support modules
├── .venv/                      # Virtual environment (auto-created)
├── .build/                     # Build artifacts (auto-created)
├── CMakeLists.txt              # Test build configuration
├── *_UnitTest.cpp              # Test source files
└── optional subdirectories     # Optional: CMakeLists and tests can be added in subdirectories
```

### Build Process
This is the process followed by the `build_unit_tests.py` script:
1. **Environment Setup** - Create/verify Python virtual environment
2. **Dependency Installation** - Install CMake, Conan, and Python tools
3. **Test Discovery** - Scan for `*_UnitTest.cpp` files in main directory and subdirectories
4. **Conan Integration** - Install Google Test dependencies via Conan
5. **AAX SDK Build** - Build core SDK with disabled optional modules
6. **Test Compilation** - Build all discovered unit test executables
7. **Test Execution** - Run all tests and collect results
8. **Reporting** - Generate test results summary

## Troubleshooting

### Common Issues

**Build Failures**: Check if problematic tests should be added to `excluded_tests.json`.

**Conan Issues**: Clear cache with `rm -rf Test/.build/.conan` and re-run.

**Python Issues**: Delete `Test/.venv` and let the script recreate it.

**CMake Issues**: Use `--clean` flag to force regeneration of build files.

### Requirements
- Python 3.8+ with venv module
- C++ compiler with C++17 support
- Git (for Conan dependencies)
